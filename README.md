# Effigy Press

A lightweight NeoForge mod that adds a simple early-game utility block for processing amethyst shards into useful resources.

## Minecraft Version

Minecraft 1.21.1

## Mod Loader

NeoForge 21.1.228

## Features

- Add the Effigy Press block
- Processes amethyst shards into useful mob drops
- JEI Integration
- Designed for survival/modpack play
- Lightweight and focused

## Installation

Drop the .jar into your mods folder.
